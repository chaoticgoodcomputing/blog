It creates the tremendous learning and understanding burden that makes personnel turnover a disaster.

This is exactly what Naur talks about. Turnover, if only one human being has the understanding in their mind, is effectively the resurrection of a project in order to get it back up-to-speed.

This is somewhat faster using LLMs, but not entirely faster. This is, again, partially because LLMs alone don’t fundamentally speed up the velocity of human understanding: it just increases the speed at which Boundary Objects can be created. However, large walls of text are not great learning objects, so I believe the optimization here (and for understanding, in in general) is a problem of how LLMs (and humans, for each other) can create better educational materials.
