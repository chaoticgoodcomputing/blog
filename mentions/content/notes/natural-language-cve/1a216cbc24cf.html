The pull request is also the point where this CVE, or “Common Vulnerability or Exposure”, exists. It goes without saying that this isn’t an actual CVE in the technical sense. Real CVEs are flaws in programs that compromise the security or stability of the program. What we’re talking about here is a bit more abstract. The human element of pull requests is not some vulnerability or exposure in the code; it’s a vulnerability or exposure in how the code gets made.
