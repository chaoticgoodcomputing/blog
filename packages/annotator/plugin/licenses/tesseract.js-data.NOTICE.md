# English language data for Tesseract

`ocr/eng.traineddata` is the `eng` model from the npm package
[`@tesseract.js-data/eng`](https://www.npmjs.com/package/@tesseract.js-data/eng) 1.0.0, its
`4.0.0_best_int` folder, unzipped. The package declares the MIT license in its `package.json` and
carries no license file of its own.

The model is Tesseract's: trained by the [Tesseract OCR](https://github.com/tesseract-ocr) project
and published in [tesseract-ocr/tessdata_best](https://github.com/tesseract-ocr/tessdata_best)
under the Apache License 2.0, whose text is beside it as `tesseract.js-core.LICENSE`.
