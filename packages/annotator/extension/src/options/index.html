By default, the extension button displays the number of annotations found on the pages you visit. Disable this if you find the badge distracting or if you do not wish the extension to ask the service it annotates against for this data.

On by default: a new tab turns Annotator on at its first web page, with its highlights shown. Turned off in a tab, it stays off in that tab. Off, Annotator waits for its button in every tab.
