## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for `chaoticgoodcomputing/blog`, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context: each Nx project (every directory with a `project.json`) has its own `CONTEXT.md`, and `CONTEXT-MAP.md` explains how to find them with Nx. See `docs/agents/domain.md`.
