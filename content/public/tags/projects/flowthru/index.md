A [[/tags/engineering/data/index|data engineering project]] that attempts to use a Kedro-style API surface to create data pipelines in [[/tags/engineering/languages/csharp/index|.NET]] that will catch errors at compile time, instead of at runtime.

The first production project using Flowthru is the analysis portions of [[/tags/projects/games/magic-atlas/index|MagicAtlas]].

Full documentation lives at [flowthru.chaoticgood.computer](https://flowthru.chaoticgood.computer/tutorials/spaceflights) — start with the [anatomy of a flow](https://flowthru.chaoticgood.computer/explanation/anatomy-of-a-flow) for the core mental model.
